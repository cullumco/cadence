# Product

## Register

brand

## Users

Developer-practitioners who use Claude Code seriously — engineers, writers, and makers who are in the tools all day and notice when something is thoughtful versus generic. Ambient-aware: they're often listening to music, in a mood, in a flow state. They care about craft in their tools, not just utility.

## Product Purpose

Cadence is an ambient context layer for agents. It reads the room — music, time, self-report, git state — and injects that state into every prompt so Claude can respond like someone who actually knows what you're in the middle of. The landing page's job is to make that idea land for a developer who has never heard of it: show them what it does in under 30 seconds, give them one clear path to install it.

## Brand Personality

Precise, ambient, human. Technical accuracy without coldness. Environmental awareness without mysticism. A tool built by someone who cares — but doesn't need to tell you that.

## Anti-references

- **Claude.ai / Anthropic** — warm cream palette, Instrument Serif, rounded editorial softness. This is NOT that.
- **Linear / Raycast** — keyboard-driven tool aesthetic, dark mode with purple/indigo accents.
- **AI startup SaaS** — hero metrics, gradient CTAs, "supercharge your workflow" copy, identical card grids.
- **Terminal cosplay** — green-on-black, fake terminal prompts, hacker aesthetic for its own sake.

## Design Principles

1. **Practice what you preach.** Cadence reads ambient context and adapts. The site itself should adapt — to time of day, to system state — so visitors experience the idea, not just read about it.
2. **Show, don't explain.** The hero demonstrates what Cadence injects. Copy that explains what the demo already shows is noise.
3. **Precision over decoration.** Every visual element earns its place. No accents for atmosphere, no depth without function.
4. **The room, not the tool.** Cadence is about the space around the work, not the work itself. The site should feel ambient — present without demanding attention.
5. **One signal, one accent.** The color comes from the moment, not a brand book.

## Accessibility & Inclusion

WCAG AA minimum. Time-of-day color adaptation must not reduce contrast below 4.5:1. Users who prefer reduced motion should see no cycling or animated transitions on ambient state changes — just the resulting color applied directly.
