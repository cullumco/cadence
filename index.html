Agents that read the room.

Claude Code has one input channel: text. Cadence is the second.

Your agent has never met you.

It doesn't know you're three beers in or up at 2am. It doesn't know you've been heads-down since six, or that the music playing is the reason you're thinking clearly. It sees the prompt. That's it.

But the prompt is a sliver of what's actually in the room. The rest — your energy, your tempo, the state you're coding in — is the context shaping everything you do. It never reaches the model.

Cadence is the channel for the rest of it.

How it works.

01 — Signals

Read the room.

What's playing becomes a vibe — read at the OS level, turned into mood words. The cadence state command lets you say what you already know: "two beers, shipping."

02 — Dials

Four knobs, not one mode.

Pace, tone, posture, proactivity — each inferred independently, or pinned by hand. High-energy-but-mellow reads as fast pace, warm tone. No single label could.

03 — Reframe

A lens, not a leash.

A sentence telling the agent how to read your prompt given the cadence. It never rewrites your words — and always defers to them.

What the agent actually sees.

Every prompt carries a state block. Inspectable. Diffable. You always see exactly what your agent saw.

<user_state>
  signals:
    music: "Loose" — Daniel Caesar
    vibe: sexy, chilled
    self_report: "two beers, shipping"
  cadence:
    { pace=fast tone=warm posture=decisive proactivity=act-freely }
  reframe: read my prompt as someone in this cadence meant it —
    fast and tight, make the call, act without checking in.
    If my words clearly mean otherwise, follow my words.
</user_state>

Install.

A Claude Code hook. macOS, Node 20+. No Spotify login, no API key — it reads what's already playing.

$ git clone github.com/cullumco/cadence && cd cadence && npm install && npm run build && npm link

Then wire one hook into ~/.claude/settings.json — see the README.

One channel of many.
